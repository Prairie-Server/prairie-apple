# Third-party logos

This catalog holds other companies' marks, kept apart from `Assets.xcassets`,
whose NOTICE covers Prairie's own brand assets.

`TMDBLogo.imageset/tmdb-logo.svg` is TMDB's approved "alt short" logo,
downloaded unmodified from <https://www.themoviedb.org/about/logos-attribution>.
It is TMDB's trademark, not Prairie's, and is not covered by this repository's
license.

Prairie shows it next to TMDB scores (`RatingEntryView`), as TMDB's API terms of
use allow. Keep the file unmodified (colours, proportions) and less prominent
than Prairie's own branding. The image set preserves vector data, so it stays
sharp at every size from one file.
